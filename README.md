# Superhero API Test Task

Тестовое задание по работе с публичным [Superhero API](https://akabab.github.io/superhero-api/).

Проект получает список супергероев, фильтрует их по полу и наличию работы и определяет самого высокого по росту подходящего героя (или героев).

## API

Используется публичный API:

https://akabab.github.io/superhero-api/

Для получения всех героев используется endpoint:

https://akabab.github.io/superhero-api/api/all.json

## Реализация

### Получение данных

Модуль `client.py` отвечает за получение списка героев из API.

### Обработка роста

Модуль `hero_height.py` содержит функцию `height_to_feet()`, которая приводит различные форматы роста к единому числовому значению в футах.

Функция перебирает все переданные значения роста. Если одно значение некорректно, проверяется следующее.

Если корректного значения нет, функция возвращает `None`.

### Поиск самого высокого героя

Функция `get_tallest_hero()` сначала отбирает героев по полу и наличию работы, после чего сравнивает их рост.

При сравнении используется числовое значение роста, полученное с помощью `height_to_feet()`.

Если несколько героев имеют одинаковый максимальный рост, они все добавляются в результат.

## Тесты

Для запуска тестов используется `pytest`.

Тесты разделены на три группы.

### Тестирование API

`test_client.py` проверяет структуру данных, получаемых от API:

Эти тесты обращаются к реальному API, поэтому для их выполнения требуется подключение к интернету.

### Тестирование преобразования роста

`test_height_to_feet.py` проверяет преобразование различных форматов роста в футы.

### Тестирование основной функции

`test_superhero.py` проверяет основную бизнес-логику функции `get_tallest_hero()`.

Проверяются следующие сценарии:

- поиск самого высокого мужчины с работой;
- поиск самого высокого мужчины без работы;
- поиск самой высокой женщины с работой;
- отсутствие подходящих героев;
- работа со значением пола `"-"`;
- неизвестное значение пола;
- наличие нескольких подходящих героев с одинаковым максимальным ростом.

Для тестирования основной функции используется фиксированный набор тестовых данных.
